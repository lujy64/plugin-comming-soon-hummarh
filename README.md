# Hummarh Coming Soon

Hecho por The Panther Soft - Vaira Maria Lujan

Plugin de WordPress para mostrar una plantilla coming soon editable con carrusel responsive.

## Que incluye

- Checkbox superior en el panel de ajustes para activar o desactivar el modo coming soon.
- Edicion de logos, textos, enlaces de botones e imagenes del carrusel.
- Carrusel vertical en escritorio y horizontal en mobile.
- Botones con hover para LinkedIn, telefono, mail y WhatsApp.
- Shortcode para Elementor o WPBakery: `[hummarh_coming_soon]`.
- Elemento WPBakery si WPBakery esta activo.
- Widget Elementor si Elementor esta activo.
- Preview estatica para GitHub en `index.html`.

## Instalacion

1. Sube esta carpeta a `wp-content/plugins/hummarh-coming-soon`.
2. Activa el plugin desde WordPress.
3. Entra en `Ajustes > Hummarh Coming Soon`.
4. Carga tus logos e imagenes reales.
5. Activa el checkbox `Activar plantilla coming soon`.

Los administradores pueden seguir navegando el sitio normal mientras los visitantes ven la pagina coming soon.

## Preview

Abre `index.html` en el navegador o publica el repositorio con GitHub Pages para ver la maqueta estatica.
